Falconia Anticheat
Private Discontinued

A manual-inspection anti-cheat for the Falconia Factions server — a required Fabric client mod ("Truesight") reports into a self-hostable admin panel, so staff can see what's actually running on a suspicious player's machine.

  • Server-side handshake — no client mod, no connection
  • Panel shows live mod folder, class names, classpaths, mixins — not just a snapshot
  • Every JAR SHA-256 hashed against known-good references, plus texture and client-diff checks
  • Independent movement/flight checks as a second layer; Discord bot built into the panel
  • Shipped 1.21.1–1.21.11, discontinued after a security incident on my machine

Alter
Private

A revival-altar / limited-lives plugin — running out of lives isn't an instant permadeath, it's a ritual other players can actually attempt to save you from.

  • Configurable life pools — running out is consequential, not instant permadeath
  • Death drops a revival focus; place it in a staff-defined altar zone to start a timed ritual
  • ProtocolLib floating/rotating head effect; PlaceholderAPI shows lives as hearts elsewhere
  • Early, smaller class-ability layer — later fully realized in the Abilities plugin below

Abilities
Private

A standalone class/progression plugin — on first join, every player gets one of 11 mythology-themed classes, each with a passive and a multi-stage ultimate.

  • 11 classes — Poseidon, Berserker, Titan, Executioner, Tempest, Inferno, Phantom, Gaia, Chronos, Nyx, Aether
  • Passives react to environment and state, not flat buffs — e.g. Berserker's Strength scales as health drops
  • Multi-stage ultimates with particle and sound cues, triggered via shift + swap-hands
  • Charge-based resource system fueled by kills, with an anti-farm cooldown
  • Paid reroll for players who want a different class; HUD + GUI for live ability status
