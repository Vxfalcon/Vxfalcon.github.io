BossEngine

A self-contained custom creature/boss engine for Paper 1.21.11, built from scratch — no MythicMobs, no Model Engine. Rig a Blockbench model, wire up abilities and AI entirely through YAML or in-game GUIs, and fight it.

JavaPaperBlockbenchYAML
Inside the project
  • Blockbench pipeline — a bbmodel importer bakes cuboids into vanilla resource-pack item models, converts every animation's keyframes automatically, and rebuilds a deployable resource pack with a built-in HTTP host, no external tooling
  • Rendering — display-entity bone rigs with real parent → child forward kinematics, so a rotating limb actually carries its children with it, driven by a frame-accurate animation clock with timed event markers for hit-frame-synced combat
  • Abilities — data-driven YAML abilities across 4 hitbox shapes (sphere/box/line/cone), 5 movement types (dash, leap, teleport, retreat, none), homing projectiles, potion/heal/ignite/launch effects, and ground telegraphs, all timed off the animation clock
  • AI — utility-style decision-making: a composable condition system (distance, health%, line-of-sight, target fleeing/blocking/healing, phase, random chance, AND/OR nesting) gates a weighted-random ability picker, on top of aggressive/neutral/friendly personalities
  • Bosses — health-threshold phases that swap ability sets and speed, synced boss bars, lockable arenas with win/fail/exit handling, configurable loot tables, and a full Bukkit event API (spawn/death/phase-change/ability-start/ability-hit/target-change) for other plugins to hook into
  • Pets — friendly creatures can be owned by a player: follow/stay toggled by right-click, automatic aggro in the owner's defense when they're attacked nearby
  • In-game editors — a model preview GUI plus full ability and boss/phase builders (hitboxes, conditions, movement, telegraphs, phases, ability toggles) with anvil-based text entry, no config file required

Private project04

Abilities

A standalone class/progression plugin — on first join, every player gets one of 11 mythology-themed classes, each with a passive and a multi-stage ultimate.

JavaPaperYAML
Inside the project
  • 11 classes — Poseidon, Berserker, Titan, Executioner, Tempest, Inferno, Phantom, Gaia, Chronos, Nyx, Aether
  • Passives react to environment and state, not flat buffs — e.g. Berserker's Strength scales as health drops
  • Multi-stage ultimates with particle and sound cues, triggered via shift + swap-hands
  • Charge-based resource system fueled by kills, with an anti-farm cooldown
  • Paid reroll for players who want a different class; HUD + GUI for live ability status
Private project05

Alter

A revival-altar / limited-lives plugin — running out of lives isn't an instant permadeath, it's a ritual other players can actually attempt to save you from.

JavaPaperProtocolLib
Inside the project
  • Configurable life pools — running out is consequential, not instant permadeath
  • Death drops a revival focus; place it in a staff-defined altar zone to start a timed ritual
  • ProtocolLib floating/rotating head effect; PlaceholderAPI shows lives as hearts elsewhere
  • Early, smaller class-ability layer — later fully realized in the Abilities plugin below
Discontinued06

Falconia Anticheat

A manual-inspection anti-cheat for the Falconia Factions server — a required Fabric client mod ("Truesight") reports into a self-hostable admin panel, so staff can see what's actually running on a suspicious player's machine.

FabricJavaNode.jsPostgreSQL
Inside the project
  • Server-side handshake — no client mod, no connection
  • Panel shows live mod folder, class names, classpaths, mixins — not just a snapshot
  • Every JAR SHA-256 hashed against known-good references, plus texture and client-diff checks
  • Independent movement/flight checks as a second layer; Discord bot built into the panel
  • Supported Minecraft 1.21.1–1.21.11. This project is discontinued.
